# One pyrometer

## About
This script is a modification of [TwoPyros](https://github.com/nemocrys/emissivity-measurement/tree/TwoPyros). The goal is to measure the emissivity of a given sample with the help of one ratio-pyrometer only. The ratio-pyrometer is alternated between the ratio and normal (mono) modes. The ratio mode is then used as the reference measurement.
