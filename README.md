# Two pyrometers

## About
This script is a rewrite of [exp-T-control_steady](https://github.com/nemocrys/emissivity-measurement/tree/exp-T-control_steady)). The goal is to get the emissivity of a given sample with the help of a ratio-pyrometer. To determin the factor k (claibrate ratio mode) use [TwoPyros_determineK](https://github.com/nemocrys/emissivity-measurement/tree/TwoPyros_with_calib).
