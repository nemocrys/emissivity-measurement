# exp-T-control with stationarity

## About
This script is a extension of [exp-T-control](https://github.com/nemocrys/exp-T-control). The Script waits for the probe temperature to reach steady state before starting the measurment. The tolernce and duration of steady state must be specified in the [heating receipe](https://github.com/nemocrys/emissivity-measurement/blob/exp-T-control_steady/Messreihe_Rezept.txt).
